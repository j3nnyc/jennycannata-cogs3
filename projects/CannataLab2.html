HTML Table Terms and Definitions

How to define a table?

Use the <table> tag to create a table in HTML. Each table is made up of rows (<tr>) and cells (<th> or <td>).

Describe when to use the following HTML elements:

  • <tr> — A table row.
  • <th> — A header cell
  • <td> — A standard data cell in a table.
  • <thead> — Groups the header content of a table.
  • <tfoot> — Groups the footer content of a table.
  • <caption> — A title or description for the table.

What is the difference between colspan and rowspan?

colspan combines cells horizontally across columns, while rowspan combines cells vertically across rows.

What is the difference between cell spacing and padding?

Cell spacing manages the space between table cells, while cell padding controls the space between the cell content and its border.

How do you define table borders using CSS?

You can define borders using the border property in CSS.

How do you control border widths using CSS?

Use the border-width property in CSS to control how thick the borders appear.
