HTML Terms and Definitions

DOCTYPE
Stands for Document Type Declaration. It's a signal to the browser about the markup language and version used in the document.
Ordered Lists
Start with the <ol> tag. Each list item starts with the <li> tag. The list items are marked with numbers by default.
Unordered Lists
Start with the <ul> tag. Each list item starts with the <li> tag. The list items are marked with bullets (small black circles) by default.
Definition Lists
The <dl> tag defines a description list. It is used with <dt> (defines the term) and <dd> (describes the term).
What is the client-server model?
The client-server model is a distributed application structure that partitions tasks or workloads between the providers of a resource or service, called servers, and service requesters, called clients. Clients initiate communication sessions with servers, which await incoming requests.
FTP
FTP stands for File Transfer Protocol. It is a standard network protocol used for the transfer of computer files between a client and server on a computer network.
HTTP
HTTP stands for HyperText Transfer Protocol. It is the foundation of data communication for the World Wide Web, where hypertext documents include hyperlinks to other resources that the user can easily access.
TCP/IP/dt>
TCP/IP stands for Transmission Control Protocol/Internet Protocol. It is a set of networking protocols that allows two or more computers to communicate. TCP/IP specifies how data is exchanged over the internet by providing end-to-end communications that identify how it should be broken into packets, addressed, transmitted, routed, and received at the destination.
